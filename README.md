# Student Performance Prediction System

A Python-based Machine Learning project that predicts student performance based on academic and study-related factors.

## Technologies Used

- Python
- Pandas
- Scikit-learn

## Features

- Data preprocessing
- Feature scaling
- Train-test splitting
- Linear Regression model training
- Model evaluation using MAE, MSE, and R² score
- Prediction for new student data

## Input Features

The model uses:

- Study Hours
- Attendance
- Previous Score

## Project Structure

student-performance-prediction/
├── README.md
├── requirements.txt
├── student_data.csv
└── student_performance_prediction.py

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the project:

python student_performance_prediction.py

## Machine Learning Workflow

1. Load the dataset
2. Select features and target variable
3. Split data into training and testing sets
4. Scale the features
5. Train the Linear Regression model
6. Evaluate the model
7. Predict student performance for new data
